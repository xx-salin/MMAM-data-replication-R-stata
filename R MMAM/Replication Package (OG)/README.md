# Replication Package — Description vs. Experience

This package reproduces the cleaned data and figures for the paper. It is
self-contained: the scripts regenerate every file in `Data/Clean Data/` from
the raw Qualtrics exports and Prolific demographics shipped alongside.

## Requirements

- R (developed on 4.4.1)
- R packages: `tidyverse`, `lubridate`, `scales`, `rprojroot`

```r
install.packages(c("tidyverse", "lubridate", "scales", "rprojroot"))
```

## How to run

Run the scripts in order, either from the command line or by `source()`-ing
them in R. Paths resolve automatically relative to this folder, so no editing
is required.

```bash
Rscript "Code/Paper/01_clean_raw_data.R"      # raw + prolific  -> clean data
Rscript "Code/Paper/02_combine_data.R"        # clean data      -> pooled combinedDF (in memory)
Rscript "Code/Paper/03_sampling_sequences.R"  # clean data      -> samplingSequences_long.csv
Rscript "Code/Paper/Pitt_talk_figs_choices.R" # choice figures  (sources 02)
Rscript "Code/Paper/Pitt_talk_figs_beliefs.R" # belief figures  (sources 02)
```

`01` and `03` write to `Data/Clean Data/`. The figure scripts source `02`
themselves, so they can be run directly.

## Key data files

**Trial-level clean files** (`v5.csv`, `v17.csv`, `prereg.csv`, …) — one row
per participant per round:

| Column | Meaning |
|--------|---------|
| `id` | Prolific participant id |
| `choiceB` | 1 if chose Asset B (the frequently-better asset), else 0 |
| `beliefA`, `beliefB` | elicited outcome estimates for each asset |
| `beliefA_below/equal/above`, `beliefB_*` | distributional belief elicitations |
| `choiceStr` | self-reported choice strength |
| `whichFirst` | which asset was displayed first |
| `short`, `round` | short (11-pair) vs long block; round number |
| `age`, `sex`, `student` | Prolific demographics |
| `df` | experiment label |

**`samplingSequences_long.csv`** — sequential treatment only; one row per
participant × round × display position. Built for the recency-bias robustness
check and attention analyses.

| Column | Meaning |
|--------|---------|
| `experiment`, `id`, `round` | identifiers |
| `block` | `single` (v17/v21/v27) or `short`/`long` (prereg) |
| `position` | display order, 1 = first pair shown |
| `nPairs` | number of pairs in this participant-round (11 or 51) |
| `isLastPair` | 1 if this pair was shown last (recency variable) |
| `outcomeA`, `outcomeB` | the two outcomes in this pair |
| `spread` | `abs(outcomeA - outcomeB)` (the extreme pair has the largest spread) |
| `viewTime` | seconds spent viewing this pair |
| `choiceB` | the participant's choice that round (repeated across positions) |
| `whichFirst`, `a3Col` | display-order / colour condition where applicable |

Display order and viewing times are positionally aligned: page _k_ shows
`position == k` and `view_k` is the time spent on it (the Qualtrics
randomization shuffles the order once and writes both the displayed pairs and
the stored sequence from the same array).
